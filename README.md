# Análise de Dados de Atendimento

## 📌 Sobre o projeto
Este projeto foi desenvolvido como parte de uma atividade acadêmica com foco em Ciência de Dados aplicada ao atendimento ao cliente.

## 🎯 Objetivo
Analisar dados de atendimento para identificar problemas, padrões e apoiar a tomada de decisão.

## 🧩 Meu papel no projeto
Neste projeto, o código base foi disponibilizado como parte da atividade.

Meu foco foi:

- Entender o funcionamento do código
- Analisar os dados gerados
- Interpretar os resultados
- Responder perguntas com base na análise
- Relacionar os resultados com decisões de negócio

## 📊 Etapas da análise
- Exploração dos dados
- Identificação de problemas
- Análise estatística
- Interpretação dos resultados
- Sugestões de melhoria

## 💡 Principais aprendizados
- Como interpretar dados de atendimento
- Como identificar padrões e problemas
- Como usar dados para apoiar decisões
- Como conectar teoria (faculdade) com prática

## 🚀 Observação
Este projeto representa meu processo de aprendizado em análise de dados, com foco em interpretação e tomada de decisão.
